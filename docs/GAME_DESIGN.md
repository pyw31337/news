# NewsBoard 게임·배지 기획 v3 (2026-10-30)

사용자 요청: 배지 세분화·단계·보상 확대, 카테고리 신설, 아이콘 다양화 / 2048·머지의 단계는 "다음이 이전을 포함하거나 더 크다"를 누구나 인정할 수 있는 사다리로 / 앵그리버드형 게임은 그래픽·물리 효과 강화 / 컨셉 → 스프라이트 → 레벨 디자인 순서 / 배경음·효과음(여러 곡, 끄고 켜기) / 개인 점수·리더보드.

## 1. 컨셉 후보와 선택

### 1-1. 이슈 2048 — "포함 관계" 사다리 (11단계, 타일 왼쪽 위에 01~11)
| 후보 | 단계 | 판단 |
|---|---|---|
| **시간** | 초 → 분 → 시간 → 하루 → 일주일 → 한 달 → 분기 → 1년 → 10년 → 100년 → 1000년 | 채택. 앞 단계가 뒤 단계 안에 정확히 들어감 |
| **우주 스케일** | 원자 → 분자 → 세포 → 사람 → 마을 → 도시 → 나라 → 지구 → 태양계 → 은하 → 우주 | 채택. 포함 관계가 교과서 수준으로 명확 |
| **데이터** | 비트 → 바이트 → 킬로 → 메가 → 기가 → 테라 → 페타 → 엑사 → 제타 → 요타 → 론나 | 채택. 1000배씩 커지는 SI 접두어(론나는 2022년 신설) |
| **뉴스 구성** | 글자 → 단어 → 문장 → 문단 → 기사 → 지면 → 신문 한 부 → 한 달 치 → 1년 치 → 10년사 → 100년사 | 채택. 서비스 주제와 맞고 포함 관계가 분명 |
| 기존 '뉴스 위상'(제보→단신→…→퓰리처) | 순서에 이견이 생김 | 폐기 (사용자 지적) |
| 화폐(1원→5만원) | 11단계를 채우려면 억지 단계 필요 | 보류 |

### 1-2. 뉴스 머지(수박 게임 방식) — "실제 크기" 사다리
| 후보 | 단계 | 판단 |
|---|---|---|
| **태양계** | 소행성 → 명왕성 → 달 → 수성 → 화성 → 금성 → 지구 → 천왕성 → 토성 → 목성 → 태양 | 채택. 실제 지름 순서 그대로 |
| **스포츠 공** | 구슬 → 탁구공 → 골프공 → 당구공 → 테니스공 → 야구공 → 소프트볼 → 핸드볼 → 배구공 → 축구공 → 농구공 | 채택. 규격 지름 순서 |
| **과일** | 블루베리 → 체리 → 딸기 → 자두 → 귤 → 사과 → 자몽 → 코코넛 → 멜론 → 수박 (10단계) | 채택. 크기 차이가 눈으로 확연한 것만 |
| 동물 크기 | 그림 품질 확보가 어려움 | 보류 |

### 1-3. 팩트 새총 — 컨셉
| 후보 | 내용 | 판단 |
|---|---|---|
| **팩트체크 특공대 vs 가짜뉴스 고블린** | 돋보기 깃털을 단 새들이 가짜뉴스 고블린이 쌓은 성을 무너뜨림 | 채택. 서비스 주제 + 원작 문법 그대로 |
| 신문사 우주 정거장 | 무중력 궤도 | 조작이 어려워 보류 |
| 편집국 대청소 | 실내 구조물 | 배경 다양성이 낮아 보류 |

- 새 4종: **팩트**(빨강, 기본) · **속보**(노랑, 화면 탭 = 가속 돌진) · **폭로**(검정, 탭 = 폭발) · **교차검증**(파랑, 탭 = 3갈래 분열)
- 적: 루머 고블린(소·중) · 가짜뉴스 왕(왕관, 체력 높음)
- 블록: 나무 · 유리 · 돌 (내구도에 따라 금 간 모습 3단계) + **가짜뉴스 상자(TNT)**
- 효과: 불꽃·파편·연기·불길·충격파·화면 흔들림·슬로모션(마지막 적 처치)

## 2. 레벨 디자인
### 2048
- 4가지 사다리 중 선택, 사다리별 최고 기록·리더보드 분리.
- 06단계 이상 합치면 빛나는 링 + 화면 흔들림, 09단계 이상은 화면 전체 섬광 + 축하 문구.
- 콤보: 한 번 밀어 2개 이상 합치면 콤보 표시·추가 점수.
### 머지
- 3가지 세트 중 선택. 다음에 떨어질 공 미리보기, 합칠 때 섬광·파티클·흔들림(단계가 높을수록 강하게), 최고 단계 2개 합치면 '완성' 연출 후 사라지며 큰 보너스.
### 팩트 새총 — 3개 월드 × 4레벨 = 12레벨
| 월드 | 배경 | 재료 | 새로 등장 |
|---|---|---|---|
| 1. 동네 소문 | 낮 하늘·언덕 | 나무 위주 | 팩트·속보 |
| 2. 온라인 커뮤니티 | 노을·도시 | 유리·나무 | 교차검증, 가짜뉴스 상자 |
| 3. 가짜뉴스 공장 | 밤·공장 굴뚝 | 돌·유리·상자 다수 | 폭로, 가짜뉴스 왕 |
- 별 3개: 남은 새 수 + 점수 기준. 이전 레벨에서 별 1개 이상이면 다음 레벨 열림.

## 3. 배지 v4
- 등급 7 → **10단계**: 브론즈 · 실버 · 골드 · 플래티넘 · 다이아 · 마스터 · 레전드 · **그랜드마스터 · 신화 · 이터널**
- 보상: 배지 등급을 처음 받을 때 XP 보너스(등급이 높을수록 큼), 커리어 직함 Lv.100까지 확장.
- 새 카테고리: 시간대(점심·퇴근길·주말), 분야 전문가(정치·경제·세계·IT과학·연예·스포츠), 탐험(타임라인·관계맵·인물·마켓·공유), 게임(콤보·별·사다리 정복), 꾸준함(누적 방문일).
- **아침형 독자 버그 수정**: 기존에는 '그날 첫 활동'이 오전 7시 전일 때만 집계돼, 자정 이후 한 번이라도 접속했다면 기록되지 않았음. 이제 시간대별로 하루 한 번씩 따로 집계.

## 4. 사운드
- 배경음: 게임별 2곡씩(2048 · 머지 · 새총), 직접 합성한 반복곡. 효과음: 이동·합치기(단계별 음높이)·콤보·발사·충돌·나무/유리/돌 파괴·폭발·승리·실패.
- 배경음·효과음은 따로 끄고 켤 수 있고, 설정은 기기에 저장.

## 5. 점수·리더보드
- 개인: 게임·사다리별 최고 점수, 최근 10판 기록.
- 전체: 로그인한 사용자만 등록. Worker `/lb`(D1 `lb` 표), 사용자당 보드별 1줄(최고 점수 갱신 시에만 씀). 별명은 직접 정하거나 자동('독자 1234').
