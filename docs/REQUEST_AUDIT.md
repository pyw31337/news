# 사용자 요청 반영 감사 — 2026-11-13

이 문서는 “커밋이 있다”와 “사용자가 실제 화면에서 요구사항을 확인했다”를 구분한다. `완료`는 코드·데이터·배포 화면까지 확인한 경우에만 사용한다. 수집량 숫자는 출처·고정 ID·사진 검수 여부가 서로 다른 지표이므로 합산하지 않는다.

## 이번 회차의 완료 조건

1. 이재명 실제 페이지에서 제21대·제22대 국회의원 및 제21대 대통령이 상세 직함으로 보인다.
2. 경력 막대와 직함 롤오버는 화면에 이미 있는 제목·기간을 반복하지 않고, 설명·출처·실제 근거 이동 경로를 제공한다.
3. 1440px와 390px에서 국회/위키 경력 및 관계 영역을 캡처로 검수한다.
4. 위 세 조건이 통과한 뒤에만 이 표의 첫 네 항목을 `완료`로 바꾼다.

## 다음 감사 순서

1. 인물 페이지의 데이터 정합성·직함·사진 매칭을 표본(대통령, 국회의원, 기자, 연예, 법조)별로 분리 감사한다.
2. `날짜 미상`, 기사 중복, 기관 로고, 연도별 사진을 각기 수치화한다. 누락을 임의 데이터로 메우지 않는다.
3. Cloudflare Worker 인증과 수집 워크플로는 실제 성공/실패 로그를 기준으로 점검한다.
4. 메인·캐러셀·날씨·카드뉴스는 PC와 모바일 회귀 검수를 별도 체크리스트로 남긴다.
