# GitHub Actions 자동 복구

`workflow-recovery.yml`은 매시 최근 24시간의 실패 실행을 읽어 `reports/workflow-recovery.json`과 Actions 요약에 남깁니다. 원본 기사·누적 데이터·미디어는 지우거나 강제 되돌리지 않습니다.

## 안전하게 한 번만 다시 실행하는 경우

- `data` 브랜치 동시 푸시 충돌
- GitHub Pages의 기존 배포 처리 중 충돌
- 일시적인 5xx·연결 시간 초과

자동 재시도는 `schedule` 또는 `push`로 시작된 **첫 실행**만 대상입니다. 수동 실행, 이미 재시도한 실행, 점검 워크플로는 보고만 합니다.

## 자동 재시도하지 않는 경우

- 비밀값·권한 오류
- Python 예외, 입력 데이터/코드 오류
- 검수 단어 풀이 소진
- 알 수 없는 실패

이 경우 보고서에 분류·실행 링크·이유만 남겨서 같은 실패를 반복하지 않습니다. 단어 풀이는 14일 완전 비중복이 물리적으로 불가능해졌을 때 검수 사전의 가장 오래된 단어만 순환 복습으로 쓰며, `data/fun.json`의 `quiz.quality.rotation`에 기록됩니다. 보조 학습 콘텐츠가 실패해도 Pages는 마지막 검수본을 유지한 채 원본 뉴스와 날씨를 배포합니다.
