# NewsBoard 게이미피케이션 (game-v1)

## 1. 벤치마크
| 앱 | 핵심 장치 | 가져온 것 |
|---|---|---|
| Duolingo | 일일 스트릭, XP, 리그, 일일 목표, 축하 화면 | 연속 일수, 일일 XP, 레벨업 축하 모달, "오늘의 도전" |
| Toss | 짧은 일일 미션, 즉시 보상, 만보기형 습관 | 3개 일일 목표 링(읽기3/OX1/게임1), XP 팝업 |
| Nike Run Club | 누적 기록 + 색상 레벨 단계 | 커리어 단계(인턴 기자 → 발행인) |
| Strava | 업적·개인 기록·트로피 케이스 | 배지 모음(내 서재), 게임 최고 기록 |
| Pokémon GO | 메달 브론즈/실버/골드 단계 수집 | 7단계 티어 메달(브론즈~레전드) |
| Apple Fitness | 링 닫기, 어워드 메달 | 일일 목표 링, SVG 메달 디자인 |

## 2. XP · 레벨
- 레벨 n에 필요한 누적 XP: `40n(n-1)+20(n-1)`
- 일일 XP 상한 400 (어뷰징 방지)
- XP: 이슈 읽기 5, OX 정답 10(만점 보너스), 덱 넘기기 2, 저장/팔로우 5, 게임 플레이 10~30
- 커리어: Lv1 인턴 기자, 3 수습 기자, 6 기자, 10 차장, 15 부장, 20 편집국장, 30 논설위원, 40 발행인

## 3. 배지 (18종 × 최대 7티어)
가입 축하, 열독가(읽기 1/10/30/50/100/300/1000), 연속 출석, 퀴즈, 만점, 어휘, 균형 잡힌 독자, 역사 탐구, 덱, 저장, 팔로우, 게이머, 이슈2048, 뉴스머지, 팩트새총, 올빼미, 얼리버드, 레벨.
SVG 메달(`NBGame.medal`)은 티어 색 그라디언트 + Tabler 아이콘, 잠금 상태는 회색.

## 4. 게임
- 이슈 2048: 제보→단신→기사→특종→헤드라인→…→퓰리처, 타일에 오늘의 키워드
- 뉴스 머지: 오늘의 인물 공 떨어뜨려 합치기(Verlet)
- 팩트 새총: 루머 블록 격파, 사실 블록 보호, 3단계 별

## 5. 저장 · 동기화
- localStorage `nb-game` (로컬 우선)
- 로그인 시 기존 My 블롭(1행)의 `game` 필드로 D1 동기화, 변경 시에만 push(디바운스) → 추가 D1 쓰기 거의 0
- 병합: `NBGameMerge` (XP/카운터 max, 배지 합집합)
