## 2. XP · 레벨
- 레벨 n에 필요한 누적 XP: `40n(n-1)+20(n-1)`
- 일일 XP 상한 400 (어뷰징 방지)
- XP: 이슈 읽기 5, OX 정답 10(만점 보너스), 덱 넘기기 2, 저장/팔로우 5, 게임 플레이 10~30
- 커리어: Lv1 인턴 기자, 3 수습 기자, 6 기자, 10 차장, 15 부장, 20 편집국장, 30 논설위원, 40 발행인

## 3. 배지 (18종 × 최대 7티어)
가입 축하, 열독가(읽기 1/10/30/50/100/300/1000), 연속 출석, 퀴즈, 만점, 어휘, 균형 잡힌 독자, 역사 탐구, 덱, 저장, 팔로우, 게이머, 이슈2048, 뉴스머지, 팩트새총, 올빼미, 얼리버드, 레벨.
SVG 메달(`NBGame.medal`)은 티어 색 그라디언트 + Tabler 아이콘, 잠금 상태는 회색.

## 4. 게임
- 이슈 2048: 제보→단신→기사→특종→헤드라인→…→퓰리처, 타일에 오늘의 키워드
- 뉴스 머지: 오늘의 인물 공 떨어뜨려 합치기(Verlet)
- 팩트 새총: 루머 블록 격파, 사실 블록 보호, 3단계 별

## 5. 저장 · 동기화
- localStorage `nb-game` (로컬 우선)
- 로그인 시 기존 My 블롭(1행)의 `game` 필드로 D1 동기화, 변경 시에만 push(디바운스) → 추가 D1 쓰기 거의 0
- 병합: `NBGameMerge` (XP/카운터 max, 배지 합집합)

## 6. game-v2 (2026-10-29)
- **배지 우표첩**: 모으지 못한 배지는 음각 빈 자리(inset 그림자, 회색 각인), 모은 배지는 양각 메달이 자리에 찍히는 애니메이션(`nb-stamp`로 처음 본 등급만 재생). 각 칸에 조건 문구·진행 막대·“n개 남음”. 누르면 상세 시트: 필요한 기록(스탯), 등급 사다리, 관련 기록 분석(카테고리·매체 성향·주제·태그·시간대).
- **OX 덱**: fun.json OX + 오늘의 단어로 만든 참/거짓 문장. 맞히면 1.3초 뒤 자동으로 다음 카드, 이전 카드로 돌아가 해설 다시 보기, 스와이프·화살표 키. 답은 `nb-oxd`(하루 단위).
- **덱↔목록 연동**: 카드 덱을 넘기면 지금까지 본 카드(01…현재)가 아래 목록에서 페이드아웃. 10장 끝까지 넘기면 하루 1번 ‘완주 스캐너’ 배지 진행 + 20 XP.
- **나중에 읽기**: 카드 오른쪽 위 버튼 → 내 서재 저장(col c0, later=1, 분석용 카테고리·키워드·인물·성향 메타 함께). 내 서재에 ‘나중에 읽기’ 목록·스크랩 컬렉션·‘나의 성향’(읽은 기사/스크랩 전환).
- 새 배지: 완주 스캐너, 나중에 읽기, 나를 아는 독자.
- D1: 모두 기존 내 서재 한 줄(M) 안에 저장, 변경 시 디바운스 동기화. 읽기 기록에 k(키워드 4)·e(인물 3)·h(시각) 추가.

## 7. game-v3 (2026-10-30) — 자세한 기획은 docs/GAME_DESIGN.md
- 배지 41종, 분류 9개(시작·성장 / 읽기 / 분야 전문가 / 시간대 / 꾸준함 / 배우기 / 탐험 / 모으기 / 게임), 등급 10단계(브론즈~레전드 + 그랜드마스터·신화·이터널). 정의: `assets/game.js` B 배열 `[id, 이름, 설명, 아이콘, 모양, 측정값, 등급 기준, 스페셜, 분류]`.
- 등급을 처음 받을 때 보너스 XP `TIER_XP=[10,20,30,50,80,120,200,300,500,800]`(하루 상한과 별개). 커리어 Lv.100까지.
- 시간대 배지(아침 5~9시·점심 12~2시·퇴근 5~8시·밤 11시~4시·주말)는 내 서재 읽기 기록(`reads[UTC날짜][id].h`)에서 날짜별로 다시 셈 → 과거 기록도 소급. 예전 버그: 그날 첫 활동 시각만 봐서 아침·밤 배지가 거의 안 나왔음.
- 배지 그림: `assets/badges/<id>-<등급>.webp`(512) · `-s.webp`(128) · `slot/<id>-<등급>.webp`(음각). 새 배지 엠블럼은 Tabler 아이콘을 3D 광택으로 렌더(`scripts/game_art/lib.mjs emblem()`), 7~9등급 프레임은 레전드 프레임을 색 변환.
- 게임: `games/g2048.js`, `games/merge.js`, `games/sling.js`(+`games/vendor/matter.min.js` MIT), 공용 `games/sound.js`(배경음·효과음 토글 `nb-snd`), `games/fx.js`, `games/board.js`(개인 기록 `nb-scores`, 전체 순위 Worker `/lb`).
