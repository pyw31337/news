## 자동화와 남은 병목

1. `collect.yml`은 30분마다 국내·해외·DART를 갱신하고, 원문·OG 이미지 재시도 로직이 적용되어 있다.
2. `legal.yml`은 3시간마다 법률 자료를 갱신하며 최근 실행은 연속 성공이다.
3. `corporate.yml`을 추가해 DART 공시 뒤 기업 도시에·임원/직원 표 추출을 뉴스 배포와 분리했다.
4. Papago 보조 번역과 Google 재시도가 배포됐지만, 무료 한도/429가 남아 있다. 번역은 원문 보존 후 재시도 큐에 남긴다.
5. 맥미니 기자 수집은 정상(최근 1시간), 로컬 AI overlay는 93시간 이상 stale이다. GitHub에서 사용자 맥미니를 원격 재시작할 수 없으므로 `macmini-watch.yml`이 6시간 경고·36시간 실패로 차단한다.
6. robots.txt는 정적 공개 페이지의 대량 크롤링을 자율적으로 거부한다. GitHub Pages는 인증·속도제한을 제공하지 않으므로 완전한 접근 차단은 Cloudflare Worker/WAF 또는 인증된 API가 필요하다.

## 시뮬레이션 공식

`남은 기간(일) = max(0, 목표량 - 현재량) / 최근 7일 일평균 증분`으로 계산한다.
법률·DART처럼 목표 우주가 변하는 스트림은 ‘완료’ 대신 최근 30일을 따라잡는 유지 모드가
정확하다. 따라서 36일/30일 같은 값은 고정된 현재 목록의 1차 스캔 ETA이며, 신규 공시와
새 인물은 계속 증분 수집된다.
