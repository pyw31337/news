# 품질 점수 (scripts/quality.py)
모든 점수 0~100, `q` 필드로 저장, 정렬 기준으로 사용(갤러리 대표 사진 = 최고 q).

| 대상 | 가중치 |
|---|---|
| 사진 | 해상도30 선명도20 원본성15 관련성15 피사체10 워터마크없음5 최신성5 |
| 기사 | 매체신뢰25 독창성25 깊이20 인용15 반응15 |
| 이슈 | 화제성30 폭20 깊이20 사진15 최신성15 |
| 인물 | 화제성35 도달25 기록25 사진15 |

- 사진 측정: PIL로 크기, 엣지 분산(선명도), 중앙 엣지 비중(피사체), 하단 밴드(워터마크)
- 캐시: data/quality_cache.json, 결과 data/quality.json
- collect.yml에서 db.py 다음 단계(실패 허용, 6분)

# 단계적 수집 (scripts/history/stage.py)
7일 → 30일 → 1년 → 3년 → 5년. 성숙 기준(건수, 일수): (12,3) (30,8) (60,20) (120,40) (200,60).
최근 30일 아카이브의 트렌드 토픽 기준, 실패 2회+비화제 시 휴면, 재화제 시 재개. hist.py는 HOT 토픽 우선.
