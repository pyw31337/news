# NewsBoard v2 디자인 시스템

v2는 인물 페이지(`/news/person/`)의 여백·위계·선 중심 레이아웃을 메인 뉴스 흐름에 적용한다. 원본 v1의 데이터 구조와 아이콘 스프라이트를 재사용하고, 메인뉴스의 증거 흐름을 한 화면에서 읽을 수 있게 한다.

## 디자인 원칙

- 배경은 `#fbfbfa`, 정보 그룹 사이에는 넓은 세로 간격(`40–72px`)을 둔다.
- 박스는 최소화하고 섹션 상단 구분선과 옅은 배경으로 관계를 표현한다.
- 제목·리드·메타·출처의 크기와 굵기를 고정해 부모/자식 위계를 유지한다.
- 모든 기사, 인물, 기관, 출처는 실제 데이터 링크로 이어진다. 데이터가 없을 때만 해당 모듈을 그리지 않는다.
- 본문 대비는 WCAG AA(본문 4.5:1 이상)를 기준으로 하며, 색상만으로 정보를 구분하지 않는다.

## 토큰

v2는 `assets/nbp/tokens.css`의 인물 페이지 토큰을 기준으로 한다.

| 역할 | 토큰 |
|---|---|
| 페이지 배경/표면 | `--c-bg` / `--c-surface` |
| 글자 위계 | `--c-ink-1` / `--c-ink-2` / `--c-ink-3` |
| 단일 강조색 | `--c-accent` (파랑) |
| 의미색 | `--c-pos` 상승·공감, `--c-neg` 하락·우려, `--c-warn` 주의 |
| 간격 | `--s-1`~`--s-10` (4px 배수) |
| 모서리 | `--r-sm` 6px, `--r-md` 10px, `--r-lg` 16px, `--r-full` 캡슐 |

## 화면 구조

1. **메인 이슈**: 가장 중요한 실제 기사 1건을 큰 이미지·제목·요약·핵심 엔티티로 노출한다.
2. **어떻게 이어졌나**: 해당 이슈의 `flow`를 시간순으로 연결하고, 각 노드는 원문 기사로 이동한다.
3. **주요 보도**: 같은 이슈의 `sources`를 언론사·썸네일·기사 제목·출처 시간으로 정리한다.
4. **분야별 주요 헤드라인**: 전체 이슈를 카테고리별로 묶어 메인 이슈와 독립적인 오늘의 흐름을 보여준다.
5. **과거와 현재의 발언**: `past`/`ai` 데이터가 존재할 때만 노출하고 원문 링크를 제공한다.
6. **관련 인물·기관 / 지금 SNS에서**: 엔티티·의견·댓글 수치를 별도 모듈로 보여준다.

## 아이콘

`assets/nbp/icons.js`의 Tabler 스프라이트를 공통 사용한다. 아이콘은 `currentColor`, 1.75px 선, 14/18/22px 세 크기만 사용한다. 제목 아이콘은 22px, 기사 메타는 14px로 정렬한다.

## 반응형·상호작용

- 1440px에서는 메인 이슈를 2열, 상세 모듈을 2열로 배치한다.
- 768px 이하에서는 모든 모듈을 세로 적층하고 썸네일은 16:9로 축소한다.
- 분야 탭, 기사 행, 타임라인 노드는 마우스·키보드·터치로 포커스된다.
- 그래프·타임라인은 0.3–0.6초 진입 애니메이션을 사용하되 `prefers-reduced-motion`이면 정지한다.
