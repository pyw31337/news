# NewsBoard 디자인 시스템 v1

스타일: `assets/ds.css` · 화면 블록: `assets/ds.js` · 견본 페이지: `/admin/design-system.html`
새 화면을 만들 때는 아래 토큰과 컴포넌트를 먼저 씁니다. 새 색·크기·굵기를 임의로 만들지 않습니다.

## 1. 토큰
| 종류 | 토큰 | 값 / 용도 |
|---|---|---|
| 브랜드 | `--ds-brand` `--ds-brand-2` | #ff4d2e (강조·현재·핵심 숫자) / #ffb020 (형광펜·보조) |
| 글자색 | `--ds-ink` `--ds-ink-2` `--ds-mute` | 제목 / 본문 / 보조 정보 |
| 의미색 | `--ds-up` `--ds-down` `--ds-violet` | 공감·상승 / 비공감·하락 / 과거 연결 |
| 카테고리 | `.ds-badge.c-정치` 등 | 정치 파랑, 경제 초록, 사회 주황, 세계 보라, IT 청록, 연예 분홍, 스포츠 귤색 |
| 간격 | `--ds-1`…`--ds-8` | 4px 단위 (4·8·12·16·20·24·32) |
| 모서리 | `--ds-r-s/m/l/pill` | 8 · 12 · 18 · 캡슐 |
| 그림자 | `--ds-sh-1` `--ds-sh-2` | 기본 카드 / 떠 있는 패널 |

## 2. 글자 (Pretendard 하나로 굵기·크기 위계)
| 단계 | 크기 | 굵기 | 쓰는 곳 |
|---|---|---|---|
| Display | `--ds-t-display` (25–40px) | 900 | 이슈 상세 제목 `.ds-title` |
| H1 | `--ds-t-h1` | 850 | 페이지 제목 |
| H2 | 21px | 850 | 섹션 제목 `.sec h2` |
| H3 | 17px | 750 | 카드 제목 |
| Body | 15px | 450 | 본문 |
| Small | 13px | 600 | 메타·보조 |
| Caption | 11px | 700 | 뱃지·라벨 |

- **세리프(Noto Serif KR)는 세 경우만**: 사람이 한 말(인용 `q.ds-say`), 의견·댓글(`.ds-cmts`), 특별 강조. 제목·숫자에는 쓰지 않습니다.
- 강조 3종 (`DS.emph()` 자동 적용): 핵심어 = 형광펜 `.ds-key` · 숫자/비율 = 크고 진하게 브랜드색 `.ds-num` · 인용 = 세리프 `.ds-say`. 문단 첫 문장은 리드 `.ds-lead` (17px/750).

## 3. 아이콘
- Tabler 외곽선(line) 아이콘만 기본, 켜짐 상태에서만 채움(`NBI(name,1)` + `.on`).
- 크기 3종: S 14px(뱃지·칩·탭) · M 18px(본문·버튼) · L 22px(섹션 제목·상단 메뉴). 선 굵기 1.75 고정, 색은 `currentColor`(글자색 따라감).
- 좋아요 = `thumb-up`, 싫어요 = `thumb-down` (하트 사용 안 함).

## 4. 뱃지 · 태그 · 칩
| 컴포넌트 | 클래스 | 규격 | 용도 |
|---|---|---|---|
| 뱃지 | `.ds-badge` | 높이 24 · 캡슐 · 12px/750 | 상태·순위·개수 (`.cat` `.rank` `.warn`) |
| 태그 | `.ds-tag` | 높이 26 · 선 1px · 12px/600 | 해시태그·공통 키워드 (`.k` 진하게) |
| 엔티티 칩 | `.chip.person/place/org/event` | 높이 26 · 연한 배경 | 누르면 이동하는 인물·장소 |
| 지표 칩 | `.schip` | 캡슐 | 상세 섹션으로 이동하는 숫자 |
| 언론사 캡슐 | `.pp` | 캡슐 안 **원형** 로고 18px | 기사 출처 |
| 언론사 로고 | `.ds-logo` `.sm/.lg` | 원형 16/20/52px | 로고 없으면 이름 첫 글자 원 |

## 5. 메뉴
- 섹션 메뉴 `.ds-tabs`: 본문 폭을 꽉 채워 균등 분배, 현재 위치에 브랜드색 밑줄. 뱃지 모양 금지.
- 기간·보기 전환 `.ds-seg`: 회색 트랙 + 흰 선택 칸 (1개월/6개월/1년/전체 등).
- PC(1000px 이상): 하단 메뉴 없음, 상단 `오늘 · 타임라인 · 마켓 · 내 서재`, 오른쪽 끝 알림 종 → 메뉴.
- 모바일: 하단 `타임라인 · 마켓 · 오늘(가운데 시계) · 내 서재 · 메뉴`.

## 6. 블록 패턴
- **목록보다 그림**: 숫자는 KPI 상자(`.ds-kpi`, `.ds-facts`), 비율은 막대·도넛, 분포는 막대 그래프, 시간은 노드 흐름(`.ds-river`).
- 시각 자료가 없으면 단계 카드(`.ds-steps`)와 강조 3종으로 읽기 쉽게.
- 긴 목록은 3개만 보이고 나머지는 접기(`.ds-more`).
- 사진: 원본이 칸 크기×2배 이상일 때만 표시(WebP 보관, `sharp.js`). 아니면 사진 칸 없이 텍스트형.
- 움직임: 0.3–0.6초, 튀는 곡선 1종. `prefers-reduced-motion`이면 모두 멈춤.

## 7. NewsBoard 필수 디자인 규정 (절대 원칙)

### 7.1 표준 날짜 표기 규격
- **기본 표준 포맷**: `YYYY.MM.DD (요일) HH:mm:ss` (예: `2026.11.06 (금) 12:36:57`)
- **날짜만 있는 경우**: `YYYY.MM.DD (요일)` (예: `2024.05.30 (목)`)
- **연월만 있는 경우**: `YYYY.MM` (예: `2024.05`)
- 모든 화면에서 날짜는 파편화된 수기 형식을 금지하며, `fDate()` 및 `NBDate.full()` 공통 포맷터를 통해 단일 규격으로 출력합니다.

### 7.2 글줄 줄바꿈 금지 및 가로 1줄 원칙 (모바일 적층 대응)
- **1줄 표기 원칙**: 뱃지, 태그, 메타 정보, 핵심 문구는 `white-space: nowrap`을 기본 적용하여 어중간하게 2줄 이상으로 줄바꿈되는 현상을 배제합니다.
- **단수 축소(세로 적층)**: 뷰포트 폭이 좁아질 때 글줄 내부를 줄바꿈하지 않고, **그리드 단수를 축소(4단 → 3단 → 2단 → 1단)하여 카드를 세로로 적층**합니다.
- 1920px 대화면부터 320px 초소형 모바일 브라우저(Safari, Whale, Chrome, Samsung Internet)까지 요소가 깨지지 않고 균일하게 정돈되도록 flex-wrap과 overflow-ellipsis를 철저히 관리합니다.

### 7.3 WCAG 2.1 가독성 및 명도 대비 준수
- **저대비 색상 조합 엄격 금지**: 붉은 배경에 분홍 글씨, 밝은 배경에 흰색 글씨, 파란 배경에 하늘색 글씨 등 대비가 취약한 배색을 전면 금지합니다.
- **최소 대비 기준**: 본문 및 메타 텍스트는 배경과의 명도 대비 최소 **4.5:1 이상(AA)**, 핵심 정보 및 뱃지는 **7:1 이상(AAA)**을 준수합니다.
- 과도한 그림자와 중첩 테두리 박스를 지양하고, 클린한 여백과 선명한 텍스트 위계로 가독성을 확보합니다.

### 7.4 언론사 표기 규칙 (심볼 아바타 + 툴팁 시스템)
- **좌측 로고 불릿**: 기사, 발언, 타임라인 목록에서 언론사 텍스트 좌측에는 항상 원형 로고 심볼(`.pl`, `q-press-emb`)을 배치합니다.
- **나열 시 심볼 전용 표기**: 여러 언론사를 나열할 때 텍스트를 길게 나열하지 않고 **원형 심볼 아이콘(`.press-sym-pill`)만 가로로 나열**합니다.
- **인터랙티브 툴팁**: 언론사 심볼을 마우스 롤오버하거나 터치하면 툴팁 말풍선(`.press-tooltip`)으로 언론사명과 보도 건수를 직관적으로 안내합니다.

### 7.5 아이콘 표준화 (Line Icon 기반 & 정중앙 정렬)
- **라인 아이콘 통일**: [Tabler Icons](https://tabler.io/icons) 및 [Lucide Icons](https://lucide.dev/) 기반의 외곽선(Line) 아이콘을 기본으로 사용하며, 크기(14~18px)와 선 굵기(1.5~2px)를 통일하여 단일 아이콘팩의 정돈된 느낌을 유지합니다.
- **가로/세로 완전 중앙 정렬**: 모든 아이콘은 뱃지나 원형 컨테이너 내부에서 `display: inline-flex; align-items: center; justify-content: center;`를 적용하여 정확히 정중앙에 위치하도록 합니다.

### 7.6 '만지는 뉴스' 인터랙션 & 재미 요소
- **세그먼트 탭 스타일(Segment Tabs)**: 상태, 단계, 기간 구분 요소는 회색 트랙과 흰색 활성 탭 구조의 세그먼트 탭을 기본 적용합니다.
- **상호 연동 차트**: 시대별 보도량 차트의 막대를 클릭/터치하면 하단 타임라인이 해당 기간으로 즉시 동기화 필터링됩니다.
- **플로우 라인 & 가로 그리드**: 차트 데이터 상단 정점을 잇는 플로우 라인(Trend Flow)과 가로 점선 그리드를 배치하여 시각적 완성도를 극대화합니다.
- **재산 신고 코인 드롭(Shower)**: 공직자 재산 신고 섹션으로 스크롤 진입 시 상단에서 황금 코인들이 쏟아지는 경쾌한 인터랙션 애니메이션(`.coin-drop-particle`)을 실행하여 주목도와 재미를 극대화합니다.

### 7.7 AI 요약 및 핵심 정보 시각화 모듈
- 법안, 주요 기사, 복잡한 사건 보도 하단에는 항상 **AI 핵심 1줄 요약(`.q-ai-summary`, `.pol-bill-drawer`)**을 결합하여, 원문 전체를 정독하지 않고도 핵심 쟁점과 입법 원안 대비 개정 골자를 3초 안에 파악할 수 있도록 제공합니다.

## 8. 인물 페이지 v2 — 공통 디자인 시스템 (2026-11-11, 사용자 승인 시안 D)
인물(`/news/person/?id=<id>`)·분류(`/news/e/?k=<키>`) 화면은 아래 v2 모듈만 씁니다. 새 화면도 이것부터 씁니다.
**이 두 화면에서는 7.2(말줄임)·7.6(동전 애니메이션)·7.7(AI 요약)을 쓰지 않습니다**: 말줄임 금지, 설명·메타 문구 금지, 지어낸 문장 금지.

| 파일 | 내용 |
|---|---|
| `assets/nbp/tokens.css` | 색(강조 1색 `--c-accent` + 의미색 pos/neg/warn + 차트 k1–k5), 글자 크기·굵기, 간격 `--s-*`, 모서리 `--r-*` |
| `assets/nbp/components.css` | 섹션 헤더 `.sh`, 사실 `.facts`/`.mini`, 수치 `.stat`/`.kpis`, 생애 단계 `.era`, 간트 `.gantt`, 연대기 `.tl`, 차트 `.hbars`/`.vbars`/`.vstack`/`.stack`/`.donut`, 인물 칩 `.pchip`, 기사 `.arow`/`.acard`/`.aday`, 발언 `.quote`(세리프는 여기만), 펼치기 `.exp`, 필터 `.seg`, 목차 `.toc`, 링크 `.lk` |
| `assets/nbp/icons.js` | Tabler 스프라이트(외곽선 `i-<이름>`, 켜짐 `i-<이름>-f`) |
| `assets/nbp/lib.js` | `NB.*` 컴포넌트 함수(HTML 문자열) + `NB.href.p(id)`·`NB.href.g(키)`(모든 링크는 이걸로), `NB.shard`, `NB.gz`, `NB.ticks` |
| `assets/nbp/person.js` · `entity.js` | 데이터 → 섹션. 자료 없는 섹션·KPI·칸은 그리지 않음 |

규칙
- 넓은 유동 폭(1440·1280·1024·768·390에서 가로 넘침·말줄임·불필요한 줄바꿈 0 — `python scripts/qa/layout_check.py <url> <폴더> 이름=경로 …`로 확인).
- 요약 먼저(첫 화면·생애 단계·KPI), 상세는 `.exp`로 펼침. 목록 항목 사이 구분선 없음, 섹션 사이만 선. 상자는 테두리 없는 옅은 바탕.
- **누르면 더 깊이**: 인물 → 인물 페이지(1계층만, 2계층은 이름만, 3계층은 안 보임), 학교·기관·직위·정당·소속·수상·직업·지역·위원회·분야 → 분류 페이지, 기사 → 원문, 법안·표결·재산 → 원 출처, 장기 기록 분류 태그 → 그 분류 필터.
- **인물은 사진과 함께**: 칩은 32px 원형(128px 원본), 첫 화면은 720px 원본을 최대 300px로(국회 사진은 원본 절반 폭까지만). 사진이 없을 때만 중립 아이콘.
