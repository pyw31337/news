# 판사·변호사 사건 이력 타임라인: 가능성 검토 (조사·시안 단계, 배포 금지)

> 2026-10-29 작성, 같은 날 13:00(한국 시간) 웹 확인 반영. 법적 근거를 확인하기 전에는 실서비스에 배포하지 않아요. 표시된 내용 중 "확인 필요" 항목은 실제 이용약관이나 API 응답으로 다시 검증해야 해요.

## 1. 한 줄 결론
- **판사:** 가능해요. 다만 "유명 사건 중심"으로만 가능해요. 판결은 공무 행위라 판사 이름을 밝히는 게 공익 보도 범위에 들어가요. 하지만 무료 공개 판례가 전체 판결의 극히 일부라서 "이 판사의 모든 판결"은 만들 수 없어요.
- **변호사:** 기록만 보여주는 건 가능해요. 하지만 순위, 승소율, "잘하는 변호사" 같은 평가는 하지 않아요. 변협 광고 규정과 로톡 분쟁 때문에 위험이 커요.
- **"관대/엄격" 표시:** 양형기준 범위 안인지 밖인지만 사실로 보여주고, 판정 단어는 쓰지 않는 게 안전해요.

## 3. 법·개인정보 위험
1. **판사:** 판결은 공무 수행이라 이름과 판결을 연결하는 건 공익성이 있어요. 단, 판결과 무관한 사생활, 인신공격 댓글, "악덕 판사" 같은 표현은 명예훼손 위험이 있어요. 사실, 출처, 원문 링크만 보여줘요.
2. **사건 당사자(피고인·피해자):** 개인정보보호법과 2차 피해 문제가 있어요. 이름을 절대 저장하거나 노출하지 않고, 사건명과 죄명만 써요 (예: "특경법 위반(횡령) 사건"). 성범죄 피해자 관련 정보는 아예 다루지 않아요.
3. **변호사:** 변협 광고 규정은 변호사 플랫폼의 순위, 승소율, 비교를 문제 삼아요. 로톡 분쟁(2021~2023년 변협 징계, 공정위 제재, 법무부의 징계 취소)이 대표 사례예요. 우리가 광고 플랫폼은 아니지만, 순위나 평가를 붙이면 분쟁 위험이 커져요. 그래서 **"이 사건을 맡았다는 보도 기록"만** 보여줘요.
4. **정확성:** 동명이인과 재판부 변경(인사이동)이 흔해요. 소속 법원과 기간까지 맞을 때만 연결하고, 확신이 없으면 "추정"이라고 표시하지 않고 아예 연결하지 않아요.
5. **정정 요청 창구:** 정정·삭제 요청 버튼과 처리 절차가 필요해요 (정보통신망법 임시조치 대응).

## 4. "기준 대비" 지표 (관대/엄격 대신)
- 양형기준표에서 범죄 유형과 감경/기본/가중 영역의 형량 범위를 가져와요.
- 선고 형량을 그 범위 위에 점으로 찍어요: **"기준 범위 아래 / 안 / 위"**.
- 필수 안내문:
  - 양형기준은 권고예요.
  - 집행유예, 합의, 전과, 경합범 같은 사정은 기사만으로 다 알 수 없어요.
  - 1심 형량은 항소심에서 바뀔 수 있어요.
- 같은 판사의 과거 판결은 같은 범죄군이 3건 이상일 때만 분포로 보여주고, 그보다 적으면 비교하지 않아요.
- 점수, 순위, "관대함 지수"는 만들지 않아요.

## 5. MVP 제안
1. **데이터:** 이미 모으는 뉴스에서 판결 보도를 추출해요. 정규식과 AI로 다음을 뽑아요.
   - 법원, 재판부, 재판장 이름
   - 죄명, 선고 형량, 선고일
   - 변호인(언급된 경우)
   - 기사 링크
2. **보강:** law.go.kr 판례 API로 대법원 판결을 붙이고(대법관 이름 포함), Wikidata로 대법관·헌법재판관의 경력을 붙여요.
3. **범위:** 처음에는 대법관, 헌법재판관, 그리고 보도된 주요 사건의 재판장만 다뤄요. 변호사는 "사건 기록 목록"까지만 보여줘요.
4. **저장:** 기존 archive 저장 방식(파일 저장소 + D1 상한)을 그대로 따라요.
5. **배포 전 확인:** law.go.kr 이용약관, 법률 자문(무료라면 대한법률구조공단이나 지자체 마을변호사), 정정 요청 절차를 먼저 갖춰요.

## 6. 화면 시안 (인물 > 법조인)
- **상단 카드:** 사진(공식 사진만), 현재 소속, 경력 타임라인(임관 → 전보 → 승진).
- **판결 타임라인:** 해마다 판결이 점으로 찍히고, 죄명 색으로 구분돼요. 점을 누르면 보도 기사와 판결 원문 링크가 열려요.
- **기준 대비 차트:** 범죄군마다 가로 막대로 양형기준 범위(감경/기본/가중)를 보여주고, 이 판사의 선고를 점으로 찍어요. 회색 안내문이 항상 함께 보여요.
- **같이 일한 사람:** 관계 그래프에 같은 재판부의 판사와 사건의 변호인이 나와요. 선은 "같은 사건"만 뜻해요.
- **하단:** 출처와 정정 요청 버튼.

## 9. 비공개 시안 v1 (/admin/legal/)
- 주소는 `/admin/legal/`이고 noindex를 걸었어요. 공개 페이지 어디에서도 연결하지 않았어요.
- 추출 스크립트는 `scripts/legal_extract.mjs`예요. 수집된 뉴스 중 판결 보도로 보이는 기사 698건을 골라 원문을 다시 읽고 다음을 뽑아요: 법원, 재판부, 재판장, 죄명, 심급, 형량, 집행유예, 무죄, 변호인.
- **기사 제목과 피고인 이름은 저장하지 않아요.**
- 결과는 판결 496건이에요. 그중 **재판장 이름이 확인된 건 3건뿐이고, 변호인은 0건이에요.**
  - 대부분이 구글뉴스 경유 링크라서 원문 본문을 읽지 못했어요. 그래서 제목에서만 추출했어요.
  - 같은 사건의 중복 보도가 많아요 (예: 공무집행방해 46건 대부분이 한 사건).
  - '무죄' 240건에는 여론조사 기사처럼 판결이 아닌 기사가 섞여 있어요.
  - 재판부 오인식도 1건 있었어요 (2심인데 1심으로 인식).
- **다음 개선:**
  1. 구글뉴스 링크를 원문 주소로 풀어서 본문을 읽기
  2. 사건 단위로 중복 보도를 묶기
  3. 판결 문맥에서만 '무죄'로 인정하기
  4. law.go.kr OC를 받은 뒤 대법원 전문에서 대법관과 변호사를 정확히 추출하기
- 스크린샷: `/workspace/newsboard-shots/legal-v1/pc.png`, `mobile.png`

## 10. 시안 v2 (2026-10-29 13:15, 한국 시간)
**바뀐 점**
1. **원문 본문 읽기:** `scripts/legal_resolve.py`가 구글뉴스 링크를 원문 주소로 풀고, 기사 본문을 읽어요. 기존 `db.py`의 `gdecode`를 재사용했어요.
2. **본문에서 추출:** 재판장(합의부, 단독, 대법원 주심)과 변호인을 본문에서 뽑아요. 성씨 목록으로 오인식을 걸러요 (예: "고법"이 이름으로 잡히던 문제).
3. **사건 단위 묶기:** 결과(형량, 무죄, 벌금), 심급, 날짜가 3일 이내로 같고, 제목 유사도가 0.45 이상이면 같은 사건으로 묶어요.
4. **판결 기사만 세기:** 제목에 판결 동사(선고, 판결, 확정 등)가 있을 때만 판결로 봐요. 다음은 제외해요: 구형, 여론조사, 고발, 비판, 해설, 상고 제기.
5. **심급 판정:** 다음 순서로 판단하고, 그 밖은 1심이에요.
   - 파기환송심 → 2심(환송)
   - 대법원, 확정 → 3심(확정)
   - 2심, 항소심, 고법, 항소부 → 2심
6. **양형기준 실제 값:** 양형위원회의 기본 영역 값을 넣었어요 (아래 표). 기사로 유형을 특정할 수 있을 때만 비교해요.
   - 사기, 횡령·배임: 피해액
   - 교통: 음주 여부와 사망 여부
   - 상해: 치사, 중상해 여부
   - 미수나 여러 혐의가 함께 있는 사건은 제외해요.
   - 살인은 동기 유형을 기사로 알 수 없어서 비교하지 않아요.

**남은 한계**
- **변호인:** 기사에 변호인 이름이 거의 나오지 않아요 (2건). 변호사 기록은 law.go.kr 판례 전문(OC 필요)에서 가져와야 해요.
- **판사 오인식:** 기사에 언급만 된 전직 대법관이 재판장으로 잡히는 경우가 있어요 (예: 과거 판결을 인용한 기사). 공개하기 전에 사람이 확인해야 해요.
- **여러 혐의가 함께인 사건:** 예를 들어 '체포방해' 사건은 여러 혐의가 함께 다뤄졌는데, 공무집행방해 1유형과 비교돼요. 이 경우 비교 표시를 끄는 규칙을 더 다듬어야 해요.
- **본문 읽기:** 309건은 본문을 읽지 못했어요. 원문 주소를 풀지 못했거나, 사이트가 접속을 막았어요.
- **양형기준의 의미:** 양형기준은 권고예요. 기본 영역 밖이라고 해서 부당하다는 뜻은 아니에요.
