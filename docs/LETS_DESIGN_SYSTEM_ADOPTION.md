# 렛츠 패밀리 디자인시스템 적용

뉴스보드 v2의 신규 화면은 [`Lets Design System`](https://github.com/pyw31337/lets/blob/main/docs/LETS_DESIGN_SYSTEM.md) v1.1.0을 기준으로 한다. 여백·정보 위계는 렛츠캘린더와 뉴스보드 인물 페이지를 기준 레퍼런스로 삼고, 공통 토큰·반응형·PWA·공유 메타데이터 규칙을 따른다. 패밀리 서비스 명칭은 `Let's Insu (렛츠인슈)`, `Let's Law (렛츠로)`로 표기한다. 기존 완성 화면은 회귀 위험이 있는 경우 예외 문서에 사유와 폐기일을 남긴다.
