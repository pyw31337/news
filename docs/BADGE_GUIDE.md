## 1. 디자인 철학
배지는 **성취의 기념품**이다. 행동했을 때 "뭔가 얻었다"는 느낌이 즉시 와야 하고, 장식이 많아도 상징이 묻히지 않아야 하며, 한눈에 "배지"로 읽혀야 한다.

## 2. 공통 구조 (반드시 지킬 것)
| 요소 | 규칙 |
|---|---|
| 프레임 | 원형 금색 메탈, 두께 일정, 광택 |
| 월계관 | 좌우 대칭, 잎 개수·방향을 세트 안에서 통일 |
| 별 | 프레임 위 **5개**(가운데가 가장 큼)로 통일 |
| 리본 | 하단 중앙, 빨강 + 금색 테두리, **두 갈래형**으로 통일. 글자 없음 |
| 상징 | 안쪽 검은 원 중앙, 원 지름의 **60~70%** |

- 원본: **정사각형 1:1**, 배경 **순수 검정**(`#000000`), 프레임 바깥 여백 **8% 이상**
- 메달 전체가 캔버스 세로의 80~90%를 차지하게(여백이 너무 크면 작게 보임)

## 4. 중앙 상징 규칙
- **주 상징 1개 + 보조 요소 1개까지**(예: 부엉이 + 초승달, 새총 + 과녁)
- 글자는 넣지 않는다(숫자 그리드처럼 상징 자체가 글자인 경우만 예외)
- 그림자는 약하게, 하이라이트는 강하게. **중간 톤 3D 일러스트**(사진·만화·손그림 금지)
- 상징의 주 재질은 **금속(금)**, 포인트 색은 1~2가지까지
- 128px로 줄여도 알아볼 수 있는 실루엣

```
A premium achievement medal, square 1:1 canvas, pure black background (#000000), 8% margin.
Round polished gold metal frame of even thickness, symmetric laurel wreaths on both sides,
five gold stars above the frame (center star largest), a two-tailed red ribbon with thin gold
edges at the bottom, no text anywhere. Inside the frame, a dark textured disc with ONE central
symbol in mid-tone 3D illustration style, mostly gold metal with at most two accent colors,
strong highlights, soft shadows, occupying 60–70% of the disc: [상징 영어로, 예: "a domed

```
- 파일 이름은 배지 id로(예: `f_pol.jpg`). 등급별로 따로 만들 필요 없음(금색 한 장만)

## 7. 파일 규칙
| 항목 | 규칙 |
|---|---|
| 사이트 파일 | `assets/badges/{id}-{tier}.webp`(512px) · `{id}-{tier}-s.webp`(128px, 64px 이하 표시에 사용) · `slot/{id}-{tier}.webp`(음각 빈 자리) |
| 등급 번호 | 0부터(0 = 브론즈). 스페셜(hello)은 `hello-2`만 |
| 포맷 | WebP 품질 86, 투명 배경, 원본당 80KB 이하 목표 |
| 256px | 따로 만들지 않음(512px를 축소 표시) |

### 그림 추가·교체 절차
1. 그록 원본(검정 배경, 1:1)을 받아 `scripts/game_art/grok_badges.py`의 `MAP`에 파일과 id를 추가
2. `python3 scripts/game_art/grok_badges.py <원본 폴더> <금색 엠블럼 폴더> <출력 폴더>` → 배경 투명화, 정사각 512/128, 10등급 색 변환, 음각 슬롯까지 생성
3. 출력물을 `assets/badges/`에 복사
4. `assets/game.js`의 `BV`(배지 그림 버전, 지금 `?v=4`)를 올리고, `sw.js` 캐시 번호와 바뀐 파일의 `?v=`를 올림
5. 배지 모음(`/news/games/#badges`)과 배지 획득 팝업에서 실제 표시 확인

## 8. 상태 표현
| 상태 | 처리 |
|---|---|
| 잠금 | 앨범의 **음각 빈 자리**(어두운 갈색 엠보싱, `slot/`) |
| 획득 | 정상 색 + 앨범 칸에 찍히는 연출(처음 볼 때 한 번) |
| 새 등급 획득 | 축하 팝업: 메달 낙하 → 섬광·불꽃 + 보너스 XP 표시 |
| 7~9등급 | 메달 뒤로 은은한 오라(`game.css` `gm-t7~9`) |

## 9. 배치
- 배지 모음: 분류(9개)별 묶음, 칸 최소 150px 자동 배치(모바일 2열)
- 누르면 상세 시트: 다음 목표, 등급 사다리(등급별 보너스 XP), 관련 기록 분석
- (다음 과제) 칸 간격 16px 이상, 터치 시 1.05배 확대

## 10. 제작 체크리스트
- [ ] 1:1 정사각, 검정 배경, 여백 8% 이상
- [ ] 프레임·월계관·별 5개·두 갈래 리본이 세트와 같은가
- [ ] 리본·상징에 글자가 없는가
- [ ] 상징이 원판의 60~70%이고 128px에서도 알아볼 수 있는가
- [ ] 주 상징 1개 + 보조 1개 이내인가
- [ ] 변환 후 7~9등급(흑요석·비취·무지개)에서도 프레임이 자연스러운가

## 11. 금지 사항
- 프레임 형태를 배지마다 다르게 하지 말 것
- 상징을 3개 이상 넣지 말 것
- 글자·긴 문장 금지
- 사진·손그림·만화 스타일 섞지 말 것
- 리본 색 변경 금지(등급 변환 스크립트도 리본은 그대로 둠)
